# Акты сверки взаимных расчетов

Локальный сайт для учёта операций с контрагентами и печати акта сверки. Данные хранятся в браузере (`localStorage`) и не отправляются на сервер.

## *Что внутри*

- Приветственный лендинг (`index.html`)
- Рабочее приложение (`app.html`): организация, контрагенты, типы операций, расчёты, печать акта
- Резервное копирование в JSON и загрузка копии обратно
- Демонстрационные данные для быстрого знакомства

## Как открыть

Самый простой способ — открыть `index.html` в браузере.

Через локальный сервер (нужен Node.js):

```bash
npm start
```

Сайт откроется на [http://localhost:4173](http://localhost:4173).

## Как работать

1. Заполните карточку **Моя организация**.
2. Добавьте контрагента.
3. Выберите период и при необходимости укажите начальное сальдо.
4. Внесите операции (начисления, оплаты, корректировки).
5. Нажмите **Сформировать акт сверки** — откроется диалог печати.

Типы операций задают направление: «+» увеличивает долг контрагента перед вашей организацией, «−» уменьшает его.

## Структура репозитория

```
index.html          лендинг

js/app.js           логика расчётов и печати
assets/             иконка
```
